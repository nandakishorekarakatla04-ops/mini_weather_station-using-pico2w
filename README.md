# mini_weather_station-using-pico2w
# Mini Weather Station Using Raspberry Pi Pico 2 W

## 📌 Project Description

This project is a **Mini Weather Station** built using the **Raspberry Pi Pico 2 W**.

It measures environmental parameters such as:

* Temperature
* Humidity
* Atmospheric pressure

The sensor values are displayed on a **16x2 I2C LCD display**.

---

## 🚀 Features

* Measures temperature using DHT22
* Measures humidity using DHT22
* Measures atmospheric pressure using BMP280
* Displays sensor readings on a 16x2 LCD
* Uses Raspberry Pi Pico 2 W
* Programmed using MicroPython
